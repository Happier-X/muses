# PRD：侧边栏对齐椒盐音乐并美化

## 背景

用户反馈：侧边栏（TabsPage 导航：移动端 50vw 推屏抽屉 + 平板 260px 固定 aside）与椒盐音乐（Salt Player）不一致，需要调整美化。

2026-08-16 在 MuMu 模拟器（1080x1920 @ 420dpi）实测椒盐音乐侧边栏（`com.salt.music`，汉堡抽屉打开态，uiautomator dump + 像素扫描）得到完整规格：

| 项 | 椒盐实测 | 转 dp（÷2.625） |
|---|---|---|
| 宽度 | 552px | 210dp（≈ 视口 50vw，Muses 51% 一致） |
| 背景 | #f9f9f9 纯色 | --m-surface-1 一致 |
| Header | 顶部 64dp 高，3 个功能小按钮（退出 / 用户界面 / 音频效果），上下 #e9e9e9 分隔线 | 64dp |
| 菜单行高 | 168px | 64dp（Muses 当前 56dp） |
| 图标区 | x48..204 | 60dp 宽列（图标 23dp 方块居中） |
| 文字左距 | x204（'歌曲' bounds [204,361][300,431]） | 77dp（Muses 当前 16dp） |
| 分组 | 主菜单（歌曲/专辑/艺术家/文件夹/歌单）+ 次菜单（扫描文件/音乐库/统计），组间 +48px 留白 | 18dp |
| 激活态 | 无背景高亮，文字一律 #1e1715 | —— |
| 菜单项 | 8 项（含 Muses 没有的页） | ——（Muses 保留自身 6 项） |

## 需求范围

仅 `src/views/TabsPage.vue` + 一个主题模式 composable（如需）。不改导航项结构（歌曲/专辑/艺术家/歌单/音源/设置 保持 6 项，不新增无页面项）。

### 1. Header 区（新增，对齐椒盐 header）
- 64dp 高，与椒盐一致的三按钮位：**✕ 关闭抽屉** / **☀️🌙 外观切换** / **⚙️ 设置**（路由跳转 /tabs/settings）
- 与菜单区分隔：顶部细线 + 底部细线（#e9e9e9 口径 = 现有 --m-hairline 或同色）
- 移动端抽屉与平板 aside 均有

### 2. 菜单排版对齐椒盐
- 行高 56dp → 64dp（`--m-list-row-h` 不动，侧边栏自用 64dp）
- 图标区固定 60dp 宽（padding-left 16dp 内图标 24dp 居中），文字从 ~77dp 起（`16 + 60 + 1 = 77dp`，与椒盐 x204px 实测一致）
- 文字 16px、行内垂直居中

### 3. 分组（主 / 次）
- 主区：歌曲 / 专辑 / 艺术家 / 歌单
- 次区：音源 / 设置（组间留白 18dp，不画线，对齐椒盐）

### 4. 激活态弱化（对齐椒盐无背景高亮）
- 去掉 `rgba(var(--m-primary-rgb), 0.12)` 背景
- 改为：文字加粗（600）+ 图标 `--m-primary`
- 保留无背景的圆角 hover/active 微反馈（可保留，但不产生蓝底常驻高亮）

### 5. 图标
- **保持 lucide 线性图标不变**（用户明确确认不改成彩色方块）

### 6. 主题切换（header 外观按钮所需）
- 现有 `useSystemDark` 只跟随系统；新增手动覆盖：支持三态 **跟随系统 → 亮 → 暗** 循环，持久化 `localStorage['muses-theme'] = 'system' | 'light' | 'dark'`
- 按钮图标随状态变化（Monitor/Sun/Moon），label 同步
- 跟随系统时行为 = 现状（监听 prefers-color-scheme 切 .dark）

## 验收标准

- [ ] 移动端打开抽屉：顶部可见 header（3 按钮 + 分隔线），菜单 6 项分两组，行高/间距/文字左距与椒沙拉齐
- [ ] 激活态无蓝底背景，通过文字加粗 + 图标主色可识别
- [ ] 深色模式：侧边栏背景 #262626（--m-surface-1 深值）、文字/图标、header 分隔线正常
- [ ] 平板宽屏（≥768px）固定 aside 同步新样式，不回归
- [ ] 外观按钮：三次点击循环 system→light→dark，刷新保持，恢复跟随系统后行为同现状
- [ ] 抽屉手势（滑开/滑关/Escape/焦点圈定/inert）无回归
- [ ] 详情页（专辑/艺术家/歌单子页）导航高亮不受影响
- [ ] vue-tsc / eslint / build 全过
