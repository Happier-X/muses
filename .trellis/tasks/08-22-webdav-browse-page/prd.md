# PRD：WebDAV 目录浏览改为独立页面

## 背景

当前 `SourceWebDavPage`（新增/编辑 WebDAV）中，「连接并浏览」后在表单下方内嵌展开目录浏览器。用户要求浏览环节改为**独立的全屏页面**，选完带着结果回到表单页。

## 需求

### R1 独立浏览页

- 新路由：`/tabs/sources/webdav/browse`，全屏展示路径导航与目录列表（复用 `WebDavDirectoryBrowser` 组件或其能力）。
- 页面带返回导航；未携带有效会话（直接深链进入）时兜底回表单页。

### R2 跨页流程

- 新增/编辑页点「连接并浏览」→ 组装凭据并校验连接（沿用现有 verify 逻辑）→ 携带会话跳转浏览页。
- 浏览页模式跟随来源：
  - **add 流程**：multiple 多选勾选，确认 → 返回表单页并批量建源（保持现状建源语义）
  - **edit 流程**：single 单选确认 → 返回表单页回填「目录」字段
- 初始路径沿用现有逻辑（编辑态从目录字段的上级开始）。
- 凭据/选择结果通过内存态服务传递，**禁止出现在 URL**；浏览页刷新拿不到会话时回表单页。

### R3 清理

- SourceWebDavPage 移除内嵌浏览区及其状态，保留连接校验与提交逻辑。
- `WebDavDirectoryBrowser` 组件契约尽量不动；如需拆分（列表渲染 vs 会话管理），以最小改动为准。

## 约束

- 遵循 `.trellis/spec/frontend/` 规范；文案简体中文。
- 本地音源流程、保存语义（密码留空保留原密码等）不变。

## 验收标准

1. 新增流程：填连接 → 连接并浏览 → 进入全屏浏览页 → 勾选多个目录确认 → 回表单页并完成批量建源。
2. 编辑流程：连接并浏览 → 全屏浏览 → 点选目录 → 返回后「目录」字段正确回填 → 保存成功。
3. 浏览页返回（不选）不产生副作用；深链直达浏览页被兜底回表单页。
4. lint / vue-tsc / 单测通过；MuMu 实测通过。
