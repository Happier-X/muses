# PRD：侧边栏卡片改椒盐分段样式

## 背景

用户三连反馈（08-16-sidebar-card-style 后）：「这个卡片跟椒盐音乐的效果不一样呢，圆角和阴影啥的」。
像素级复核（s2.png 椒盐干净打开态，线性扫描）发现上一版做错了：

**椒盐抽屉真实结构 = 分段圆角面板，不是整张卡**：
- 主菜单段：y312..1152（r≈30-40px 物理 ≈ 12-15dp 圆角；左右缘 x48..551，1px #e9e9e9 描边）
- 次菜单段：y1200..1700（同样式）
- 两段间空隙：y1152..1200 等 48px（18dp），**空隙区纯 #f3f3f3 无投影**
- **无投影**（0 8px 24px 阴影是我上一版臆造）
- 顶/底部圆角边界线性扫描确认（y1130 左缘 x56 → y1148 左缘 x80 → y1152 结束）

Muses 上一版错误：整张 24px 圆角大卡 + `0 8px 24px rgba(0,0,0,0.08)` 阴影 → 与椒盐差很多。

## 需求（仅 TabsPage.vue 样式）

1. **拆整卡为两张分段卡片**：
   - 主菜单卡（`--primary`，4 项歌曲/专辑/艺术家/歌单）+ 次菜单卡（`--secondary`，2 项音源/设置）
   - 每张：`background: var(--m-surface-1)`、`border: 1px solid var(--m-hairline)`、`border-radius: 16px`（--m-radius-md，≈椒盐 15dp）、**无 box-shadow**
   - 左空隙 18px、右空隙 12px（椒盐实测 x48/x552 保持）
   - 段间空隙 18px（`margin-top: 18px`），首卡顶部 8px（`padding-top: 8px`）
2. **去掉阴影**（椒盐无投影）
3. 深色模式：卡片背景自动 #262626、描边自动
4. 平板 aside 保持现状
5. 其余契约不变（64px 行高、图标灰、drawer 内 padding-left 0、激活仅文字加粗）
