# 将底部导航改为 Salt 侧边栏

## Goal

将移动端一级导航从固定底部 Tabbar 改为符合 Salt Player 使用习惯的左侧抽屉导航，使用户可通过侧滑打开主导航并在歌曲、音乐库、音源、设置间切换；保留现有路由、播放和页面业务行为。

## 已确认事实

- `TabsPage.vue` 在移动端渲染四项固定底部 Tabbar，平板（宽度 >= 768px）渲染 260px 固定左侧导航。
- 一级路由为 `/tabs/songs`、`/tabs/categories`、`/tabs/sources`、`/tabs/settings`；详情页仍归属其父入口。
- `MiniPlayer`、全局内容止位和安全区目前以移动端 64px Tabbar 为几何基准。
- 应用使用 Vue 3、vue-router、motion-v 和自研 `m-*` 组件；不引入第三方 UI 组件库，不改变业务逻辑、数据流、路由路径或组件既有 API。

## Requirements

- 移除移动端固定底部 Tabbar，改为左侧滑出式主导航抽屉；平板固定左栏维持并在视觉与菜单内容上对齐。
- 抽屉包含当前四个一级入口，当前路由必须正确高亮；选择入口后关闭抽屉并执行既有路由跳转。
- 打开抽屉时提供遮罩、焦点/点击隔离及关闭动作；不得与播放器、队列、Dialog、Popup 等既有弹层层级冲突。
- 更新 MiniPlayer 与全局内容底部止位，移除已失效的 64px Tabbar 预留，保留安全区和 MiniPlayer 避让。
- 抽屉及遮罩的显隐动画使用 motion-v；纯颜色或 opacity 变化可使用 CSS transition。
- 延续 Salt 主题 token、干净表面和 hairline 规则，不恢复 iOS 玻璃风格。

## Acceptance Criteria

- [ ] 移动端不再显示固定底部 Tabbar，页面底部无 64px 导航空带。
- [ ] 用户可以用已确认的入口打开左侧导航，并可可靠关闭。
- [ ] 四个一级入口正确导航、当前路由高亮；进入详情页后父入口仍正确高亮。
- [ ] 选择菜单项后抽屉关闭；抽屉打开时点击遮罩不触发页面内容。
- [ ] MiniPlayer 在有/无播放歌曲时位置正确；空状态 MiniPlayer 仍显示，内容始终避让 64px MiniPlayer 与底部安全区。
- [ ] 平板固定左栏和移动端抽屉的菜单项、激活态与 Salt 视觉一致。
- [ ] `npm run build`、`npm run lint`、`git diff --check` 通过；Android MuMu 上启动无 JS/Vue 错误或崩溃。

## Out of Scope

- 不增加或删除一级导航入口，不修改路由路径或详情页信息架构。
- 不实现动态壁纸取色、SALT FX、小部件或桌面端专用布局重做。
- 不改造播放器、队列、歌词、扫描等业务功能。

## 已确认交互

- 移动端整个页面支持从任意位置向右滑打开导航抽屉。
- 抽屉打开后支持向左滑关闭。
- 页面左上角保留汉堡菜单图标，点击打开抽屉。
- 侧滑打开手势覆盖整个移动端页面，不要求从左边缘开始；仅在识别为水平右滑时触发，避免与页面垂直滚动冲突。抽屉打开后的左滑关闭覆盖抽屉内容区域。
- 手势与汉堡按钮共享同一抽屉状态和关闭逻辑。
