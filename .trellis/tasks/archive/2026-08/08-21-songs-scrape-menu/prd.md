# 歌曲页刮削菜单重构

## Goal
将歌曲页顶部工具条从“随机播放 + 筛选可疑 + 刮削队列”三图标，重构为“仅随机播放图标+数字”，其余两个功能收进名为「刮削」的单独菜单，提升工具条简洁度与功能聚合度。

## Background
- 现状 `SongsPage.vue` 工具条左侧：shuffle（随机播放全部）、crosshair（筛选可疑歌曲批量入队，带 disabled）、listChecks（刮削队列，带 badge 计数并跳转 /scrape）+ 歌曲总数 `songs.length`
- 痛点：工具条图标过多，刮削相关功能分散，不符“刮削”功能聚合需求
- 关联：c32a622 新增刮削队列入口图标+徽标

## Scope
- In Scope:
  - 工具条左侧仅保留：随机播放图标按钮 + 歌曲数字
  - 新增「刮削」菜单触发入口（图标/文字/徽标按设计）
  - 菜单内包含：筛选可疑歌曲批量入队、刮削队列入口（跳转 /scrape，带计数）
  - 保留原有 disabled/徽标/确认框逻辑
  - 响应式/深色主题适配
- Out of Scope:
  - 刮削队列页 /scrape 本身改动
  - 随机播放逻辑改动
  - 搜索、多选、索引条等其他区域

## Acceptance Criteria
1. 顶部工具条左侧仅显示随机播放图标与歌曲数字，无 crosshair/listChecks 独立图标
2. 存在「刮削」菜单入口，点击弹出菜单
3. 菜单内可执行筛选可疑歌曲（disabled 态、计数、确认框）与跳转刮削队列（徽标/计数同步）
4. 徽标计数在菜单触发处与菜单项内均正确显示（0 时隐藏 ，>99 显示 99+）
5. 深色/浅色、移动端样式正常，无布局错位

## Key Decisions
- 菜单形态：`m-actions` 底部弹出（与页内其他菜单一致）
- 触发样式：工具条新增「刮削」按钮（`listChecks` 图标 + 文字「刮削」 + 徽标计数），点击弹出菜单
- 菜单内容：1) 筛选可疑歌曲（`suspiciousCount`，为 0 时 disabled） 2) 刮削队列（`scrapeQueueCount` 徽标，跳转 /scrape）
