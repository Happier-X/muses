# PRD：WebDAV 音源目录浏览器（添加/编辑通用）

## 背景

- 用户反馈：编辑 WebDAV 音源时无法选择文件夹，「目录」只能手动输入路径，容易填错且不知道服务器上有什么目录。
- 现状：**添加** WebDAV 时已有目录浏览器（连接后逐级浏览、勾选多个目录批量添加），但该浏览器的 UI 与状态全部内联在 `SourcesPage.vue` 的添加表单 sheet 中，无法在编辑流程复用。
- 底层能力已具备：`listWebDavDirectories(connection, path)` 返回指定路径下的子目录列表。

## 目标

1. 编辑 WebDAV 音源时，可以浏览服务器目录树并点选目录，回填到「目录」字段。
2. 将目录浏览能力抽取为可复用组件，添加流程与编辑流程共用同一实现，消除重复。

## 需求明细

### R1 编辑流程支持浏览选目录

- 编辑对话框中（WebDAV 类型）提供「浏览目录」入口。
- 点击后打开目录浏览器：显示当前路径、支持进入子目录、返回上级。
- 单选模式：选中某个目录后确认，回填编辑表单的 `path` 字段，关闭浏览器。
- 浏览使用的凭据：服务器地址/用户名取编辑表单当前值；密码为空时使用安全存储中的原密码（`getWebDavPassword`），不为空则用新输入值。
- 认证失败/读取失败时 toast 提示（复用现有错误文案风格），浏览器保持打开。

### R2 目录浏览器抽取为共享组件

- 将「逐级浏览 + 路径导航」的 UI 与状态封装为独立组件（建议 `src/components/ui/` 或 feature 组件目录，见 design）。
- 支持两种模式：多选勾选（添加流程现状）与单选确认（编辑流程新增）。
- 添加流程迁移到该组件，行为不回归：连接、浏览、多选、批量添加均保持现状交互。

### R3 不改动的能力边界

- 本地音源的「重新选择目录」（系统文件夹选择器）不在本任务范围内。
- WebDAV 连接验证逻辑（保存时的 verify）不变。

## 约束

- 遵循 `.trellis/spec/frontend/` 组件规范（浮层 Teleport、z-index 阶梯、motion-v 动画等）。
- UI 文案简体中文，风格与现有页面一致。

## 验收标准

1. 编辑 WebDAV 音源 → 点「浏览目录」→ 能逐级浏览 → 选中目录确认后「目录」字段被正确回填。
2. 密码留空编辑时浏览功能可用（使用原密码）；修改密码后浏览使用新密码。
3. 添加 WebDAV 流程行为与现状一致（多选批量添加不回归）。
4. 认证失败时有明确 toast 提示，不崩溃、不留死界面。
5. lint / vue-tsc / 单元测试通过；真机（MuMu 模拟器）实测通过。
