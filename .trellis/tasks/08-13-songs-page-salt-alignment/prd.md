# 歌曲页对齐椒盐音乐（视觉深仿 B 方案）

## Goal

将 Muses **歌曲页**（SongsPage）按椒盐音乐（Salt Player v12.2.0，用户提供 APK 实测）的界面做**视觉深仿**：不仅配色，连**页面结构、行内布局、工具条、字母索引条**都对齐椒盐的真实界面。核心是让歌曲页「一眼看去就是椒盐的审美与结构」。

**用户价值**：Muses 歌曲页目前只有「标题 + 随机播放条 + 列表」，功能信息密度低；椒盐歌曲页有工具条（排序/多选/全选）、右侧字母索引条、行内双按钮等结构，更接近专业本地播放器。用户明确选择方案 B（视觉深仿，含行内细节），非 A（仅结构）或 C（仅索引条）。

## Background（APK 实测事实，MuMu 模拟器 1080x1920 @480dpi=3x）

椒盐歌曲页实测结构（自上而下）：

1. **顶部 navbar**（y 0-228，76dp）：
   - 左侧汉堡按钮 [12,84][156,228]
   - 标题「歌曲」[168,119][270,193]（16px 字）
   - 右侧搜索按钮 [936,96][1056,216]；点击后变「在 N 首歌曲中搜索」输入框 + 取消
2. **工具条**（y 228-372，48dp，表面色 + 无分割线）：
   - 左侧「全选/圆形图标」按钮 [0,240][238,360]（多选模式显示「全选」文字）
   - 右侧「排序」按钮 [792,228][924,372]（desc=排序）
   - 右侧「多选」按钮 [924,228][1068,372]（desc=多选）
   - 排序菜单项：自定义/标题/专辑(音轨)/大小/文件夹(标题)/文件名/艺术家(专辑)/年份/播放次数/时长(短→长)/时长(长→短)/修改时间/添加时间
   - 多选模式：顶部变「已选中 N 项」+ 全选；底部操作条「永久删除/添加到歌单/播放选中队列」
3. **歌曲列表**（y 372 起，行高 216px = 72dp）：
   - 行内左侧：封面（50dp 方形，[48,393][198,543]；无封面显示占位圆图标）
   - 行内文字：标题（16px 主文字 #1E1715）+ 副标题（12px 次文字 #8C8C8C）
   - 行内右侧：圆形按钮（约 42px 直径，含加号/十字图标，点击无弹层——疑似加入队列）+ 「⋯」菜单按钮（弹出：添加到歌单/下一首播放/分享/艺术家：xx/专辑：xx/使用音乐标签应用编辑…/歌曲信息/永久删除）
   - 无分割线；正在播放行无背景高亮（对比 Muses 现在有 10% 主色底）
4. **右侧字母索引条**（x 1032-1080，16dp 宽，可拖动跳转）：
   - 顶部「0」标记（[1068,219][1080,228]，疑似回顶/定位）
   - 字母渲染 C-Z + #，每字母 45px=15dp 高、约 12px 字、统一灰 #A6A6A6（无高亮区分）
   - A/B 字母位置被工具条「多选」按钮（y 228-372）视觉遮挡——即索引条实际渲染完整 A-Z + #，但上半部分在工具条后方
   - 点击字母/拖动可跳转列表（实测 # 跳转生效）；仅特定排序下显示（Telegram 官方日志：滚动指示条"仅特定排序下"）
5. **底部 MiniPlayer**（y 1698-1920，74dp）：封面 + 歌名 + 副标题 + 右侧「播放队列」按钮

与 Muses 现状差距点：①无工具条（排序/多选/全选）；②无字母索引条；③无搜索入口；④行内无封面占位/圆形按钮；⑤正在播放行有高亮底（椒盐无）；⑥行高 72dp vs 现在 56px。

## Requirements

- **R1 工具条**：歌曲页 navbar 下方新增 48dp 工具条（表面色），含左侧全选（多选时显示）/ 右侧排序 + 多选按钮；排序按钮弹出椒盐同款排序菜单
- **R2 排序**：实现椒盐排序菜单中的可用项——自定义（当前显示顺序）/标题/文件名/艺术家/专辑/时长/年份/大小（有数据的字段）；文件夹/播放次数/修改时间/添加时间按 SongItem 支持情况取舍
- **R3 多选**：多选按钮进入多选模式——顶部「已选中 N 项」+ 全选切换；行前出现选择框（视觉对齐椒盐）；底部操作条「永久删除/添加到歌单/播放选中队列」；播放选中队列复用现有队列能力
- **R4 字母索引条**：右侧 16dp 宽可拖动索引条（A-Z + # + 顶部 0），点击/拖动跳转列表对应分组；仅排序为「标题/文件名」等字母序排序时显示；索引分组基于歌曲标题首字符（数字→#，字母→对应字母，中文按 localeCompare 归属 # 或拼音首字母——需在实现时决策）
- **R5 行内视觉**：行高 56→72dp（或按椒盐视觉调整）、封面 50dp 方形占位（无封面显示圆占位图标）、行内加圆形按钮（加队列）+ 菜单按钮、副标题文案与椒盐对齐（歌手 - 专辑 或按椒盐实际）、移除正在播放行高亮底（若椒盐无）
- **R6 搜索入口**：navbar 右侧搜索按钮 → 顶部「在 N 首歌曲中搜索」输入框 + 取消；过滤列表即时更新
- **R7 交互一致性**：行点击播放、菜单弹出椒盐同款操作列表、底部 MiniPlayer 不变

## Acceptance Criteria

- [ ] AC1：`npm run build` + `npm run lint` 全绿
- [ ] AC2：歌曲页出现工具条（排序/多选/全选按钮），视觉对齐椒盐（48dp 高、表面色、无分割线）
- [ ] AC3：排序按钮弹出椒盐同款菜单，可用排序项生效（列表顺序变化）；字母索引条仅在标题/文件名等字母序排序下显示
- [ ] AC4：多选模式完整可用——全选/单选、计数、永久删除/添加到歌单/播放选中队列均生效
- [ ] AC5：右侧字母索引条渲染 A-Z + #（含顶部 0），点击/拖动可跳转分组，无歌字母可置灰或隐藏（与椒盐视觉一致：统一灰）
- [ ] AC6：行内布局对齐椒盐——行高 72dp、50dp 封面（含无封面占位）、圆形加队列按钮 + 菜单按钮、副标题格式对齐
- [ ] AC7：搜索按钮 → 输入框过滤生效，可清空/取消
- [ ] AC8：播放/队列/编辑/扫描/虚拟列表零回归（手动验证 MuMu 全流程）；正在播放行高亮移除后仍有当前歌曲视觉指示（如椒盐的行内图标）

## Out of Scope（明确不做）

- ❌ 不改其他页面（仅 SongsPage）；不动播放器页/专辑页/艺术家页
- ❌ 不做 Material You 动态取色（椒盐的壁纸取色）
- ❌ 不做文件夹浏览树、统计页、DLNA、桌面端
- ❌ 不做拼音首字母库引入（中文歌按 localeCompare 归属 # 组，除非实现时发现必须；见 R4 决策点）
- ❌ 不重构队列/播放器核心逻辑，只复用现有能力
- ❌ 不做"记忆式简易首页"（椒盐首页形态，超出歌曲页范围）

## Notes

- 视觉对照依据：用户提供 APK（v12.2.0）在 MuMu 模拟器实测 + SaltUI 开源组件库源码（ui2/）已取证
- 已确认设计参数：行高 72dp、工具条 48dp、封面 50dp、索引条 16dp 宽/15dp 字母间距/12px 字/#A6A6A6 灰、排序菜单 13 项
- 关键实现决策点（design.md 中定）：①中文歌索引归属（# 或拼音）；②无歌字母显示置灰还是隐藏；③正在播放行的视觉指示形式；④大小/年份/文件夹等排序字段的数据来源
