# 复刻椒盐沉浸式播放页平板模式

## Goal

将 muses 播放页平板（横屏 ≥768px 逻辑宽）布局从"占位双栏（控制内嵌左栏）"升级为**双栏 + 全宽底部控制条**，竖屏（含竖屏平板）保持手机式全屏沉浸不变。视觉风格延续现有椒盐式沉浸（深色全屏 AMLL 背景）。

## 背景与参考

截图存于 `refs/`（MuMu 模拟器实测椒盐 12.2.0）：
- `landscape-home.png` / `landscape-home2.png`：横屏平板主界面
- `landscape-lyric-default.png` / `landscape-lyric3.png`：横屏平板播放页歌词页
- `landscape-info.png` / `landscape-musichall.png`：横屏平板播放页信息页
- `portrait-player.png`：竖屏平板播放页（手机式全屏）

椒盐实测行为：横屏播放页内容限宽偏左、右侧音乐厅氛围区；竖屏手机式全屏。muses 本次**不**复刻椒盐"单列偏置"形态，采用用户决策的双栏布局。

## Requirements

- **R1 双栏**：平板播放页保留左右双栏——左栏信息面板 + 右栏歌词面板（用户决策 08-17）。
- **R2 控制下移**：进度条 / 上一曲·播放·下一曲 / 循环·随机·队列·更多 模式按钮，全部从 info-panel 移出，下移到底部**全宽固定控制条**（用户决策 08-17），左栏不再内嵌控制区。
- **R3 断点**：仅**横屏且 ≥768px 逻辑宽**启用双栏 + 底部控制条；竖屏（含 800x1280 竖屏平板）保持手机式全屏沉浸（用户决策 08-17）。
- **R4 背景**：保持现有 AMLL `BackgroundRender`（封面取色 + Mesh 渐变 + 流动效果），双栏时全屏铺满、左右两栏共享（用户决策 08-17）。
- **R5 手机零回归**：<768px 手机布局（固定头部 + 大封面 + 五行歌词窗口 + 内嵌控制）与横屏手机（<768px 宽）完全不变。

## Acceptance Criteria

- [ ] AC1 横屏平板（≥768px 宽）：左右双栏渲染，左栏 = 歌名/艺术家头部 + 大封面；右栏 = 歌名/艺术家头部 + AMLL 歌词；中间无进度/控制/模式按钮。
- [ ] AC2 横屏平板：底部固定控制条横跨全宽，包含进度条 + 时间 + 上一曲/播放/下一曲 + 循环/随机/队列/更多；进度条可拖动 seek，按钮功能与手机一致。
- [ ] AC3 竖屏平板（如 800x1280）与手机（<768px）：布局与改动前完全一致（手机式全屏沉浸，无底部控制条，无双栏）。
- [ ] AC4 横屏手机（宽度 <768px 的窄高屏）：保持现有窄高屏处理（单行歌词等），不出现双栏或底部控制条。
- [ ] AC5 背景全屏铺满，双栏左右共享同一 AMLL 背景；下滑关闭、左右切面板（手机）、歌词浮动 chrome 等现有交互无回归。
- [ ] AC6 平板下无 currentSong 空状态、编辑歌曲信息/更多菜单等弹层功能正常。
- [ ] AC7 lint / vue-tsc / build 全绿；模拟器平板横屏实测布局符合 AC1-AC3。

## Out of Scope

- 不复刻椒盐"横屏单列偏置 + 右侧音乐厅氛围区"形态（用户选双栏）。
- 不做椒盐"音乐厅氛围效果"增强（保持现有 AMLL 背景，用户决策）。
- 不改动主界面（侧边栏/列表）平板布局。
- 不做歌词页详情面板（常亮开关/DLNA/音频信息/评论区）——muses 无此功能，不新增。
