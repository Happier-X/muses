# 内置免费音源

来源：[guoyue2010/lxmusic-](https://github.com/guoyue2010/lxmusic-)，目录 `V260907`，固定提交 `4b6ddafad26fed0b6cbe029a3cc8dcd7fd7e8cd7`。

保留脚本头部作者、名称和版本声明。合集仓库采用 Apache-2.0；墨澜和星澜脚本另有 MIT 声明，均保留在脚本中。

内置版本的西瓜聚合关闭 HYW 卡密通道并清空卡密，仅使用其他公开接口。其余脚本保留原文。上游接口可用性取决于各音源服务。

应用首次使用时将脚本安装到音源文件库。已有相同原文的脚本不会重复添加；安装标记永久保留，用户编辑、禁用或删除后，重启不会覆盖或重新添加。

设置中的「使用内置 LX 音源」默认开启；关闭后只使用用户自行导入的脚本，并暂停内置更新。开启时每七天检查合集的最新版本目录，仅更新已内置且名称匹配的脚本，不自动新增未知或付费脚本。更新前先校验脚本，失败保留旧版并在一天后重试。

每个脚本记录应用管理版本的原文指纹，用户编辑过的原文不会被自动覆盖；禁用标记与删除状态也会保留。Android 使用有网络约束的每周后台任务，同时在应用运行时补查；桌面在应用运行期间检查，退出时暂停，下次启动补查到期更新。
