# AMLL 歌词滚动与逐字特效移植

参考项目：[applemusic-like-lyrics](https://github.com/amll-dev/applemusic-like-lyrics)。
对照提交：`86200dead453bb067e554e989110cbadca8d4756`，核心包版本 `0.6.0`。

## 对照规则

- `packages/core/src/lyric-player/base/spring.ts`：正常切行根据前后两行的起始时间差，在 170～220 之间选择刚度；跳转和间奏采用刚度 90、阻尼 15；结束采用刚度 140、阻尼 22。
- `packages/core/src/utils/spring.ts`：上游把过阻尼按临界阻尼求解，因此移植时将 Compose 阻尼比上限设为 1。保留每行像素坐标和速度，后续切行更新目标；等待新的阶梯延迟时，之前的动画继续运行。
- `packages/core/src/lyric-player/base/index.ts`：目标行块中心位于视口高度的 35%；阶梯延迟从 50 毫秒开始，焦点之后每行除以 1.05；目标位置已离开视口上方的行不累计延迟。跳转不使用阶梯延迟。
- `packages/core/src/lyric-player/base/group.ts`：播放时非焦点行缩小为 97%，当前行恢复到 100%；暂停恢复所有行大小。
- `packages/core/src/lyric-player/dom/lyric-group.ts`：初次显示时从视口下方两倍高度飞入，不施加阶梯延迟。
- `packages/core/src/lyric-player/base/index.ts`、`dom/lyric-group.ts`：按行距离施加最多 5 个逻辑像素的模糊，触摸浏览时清除模糊。
- `packages/core/src/lyric-player/base/scroll.ts`：浏览结束后的回归等待为 500 毫秒，包含惯性滚动；即便当前句未变化也重新对齐。

## 原生适配

Android 与桌面端共享 Compose 实现。位移在图层中读取，避免每帧因读取列表布局信息而重新组合所有歌词。底层保留惰性列表与预取；已测量的行使用真实高度，远距离跳转先按估算高度移动，再用真实布局收敛。译文、罗马音、对唱数据和歌词来源继续沿用 Muses，逐字绘制已替换为以下规则。

动画使用 Compose 动画时钟，服从系统动画缩放和减少动态效果设置。模糊使用图层模糊，不再用白色阴影替代距离模糊；Android 12 以下系统不支持该图层效果。低画质关闭模糊，中画质降低模糊强度。

## 逐字特效

- `dom/animation/mask/animator-web.ts`：遮罩根据真实词宽与原始音节时间线性推进，保留词间停顿；首词补偿 1.5 倍羽化宽度、尾词补偿 0.5 倍。羽化宽度为词高的 0.5 倍，使用连续渐变，不再分成三段透明度。
- `dom/animation/float/index.ts`：普通词按缓出曲线上浮 0.05 个字号单位，持续时间不小于 1000 毫秒；和声幅度加倍。
- `dom/animation/emphasize/index.ts`：强调词采用上游的 32 帧双贝塞尔包络。字符起步错开时长除以 2.5 再除以字素数；额外上浮提前 400 毫秒，持续时间为强调时长的 1.4 倍。句尾放大、辉光和时长分别乘以 1.6、1.5、1.2。
- `utils/lyric-split-words.ts`：无空格的英文多音节共用强调组，中文按字分时；至少 1000 毫秒的中文字符或长度为 2～7 的非中文词才触发强调。绘制按完整字素处理组合音标、代理对和组合表情。
- `styles/lyric-player.module.css`：当前行逐字遮罩使用 1 / 0.4 明暗值，非活跃行使用 0.2；激活和退出交接分别为 300 / 450 毫秒。
- `packages/ttml/src/parser.ts` 与逐字遮罩中的 Ruby 分支：解析 `tts:ruby` 容器、主字和注音片段，保留各片段的独立时间；按注音字符数分配主字高亮宽度，片段间停顿冻结。注音以主字一半字号绘制在上方，与主字一起换行，并为较宽注音预留空间。带注音词不再按普通汉字拆分，其强调字符数使用注音长度。

词容器使用独立绘制层：先画子字素的缩放和辉光，再应用整词遮罩。辉光透明度直接传给绘制，不再把半径缩至 12%；原先自定义的正弦抖动已经移除。词动画直接由播放时间求值，暂停、倒退与跳转不依赖累计动画状态。减少动态效果及系统禁用动画时关闭形变与辉光，但保留逐词高亮的时间同步。

移植范围包含歌词滚动、逐字特效及带独立时间的 TTML Ruby 注音，不包含 AMLL 网页背景、编辑器和音频播放器。Ruby 注音独立存储在音节上，不与现有行级罗马音和译文混用；无有效时间的 Ruby 保留正文，暂不显示注音。字体度量、触摸惯性和惰性布局由原生平台提供，不能据源码参数一致宣称逐像素一致。
