# v0.2.6

## UI 框架迁移（Konsta UI v5）

- **全面迁移 Konsta UI v5（iOS 主题）**：移除自研组件库，采用系统蓝、iOS 分组列表与原生质感。
- **TabBar 修复**：图标恢复 iOS 规范布局（图标上文字下），圆形高亮底。
- **弹层层级统一**：添加音源等底部弹层不再被底部导航和迷你播放器遮挡；统一提升遮罩层层级。
- **按钮统一**：所有按钮统一 Konsta rounded 圆角胶囊；危险操作（删除等）用 iOS 系统红按钮。
- **旧 WebView 兼容**：修复旧版 Android 系统 WebView 下导航栏/标签栏渐变背景透明、红色按钮不显示的问题。

## 音源管理

- 添加/编辑音源、扫描设置、扫描进度改为居中对话框；右上角 + 添加音源恢复底部弹层。

## 播放队列

- 播放队列改为底部弹出面板（默认半屏高度），不再是全屏页面。

## 库详情页

- 专辑/艺术家可点击进入详情页；补齐随机播放全部与跳转当前歌曲气泡。

## 编辑歌曲元信息

- 歌词渠道与元信息渠道拆分 tab；云端元信息支持来源平台选择（MusicTag 式 chips）；歌词云端获取聚合库始终参与。

## 播放器修复

- 首次播放进度条不再瞬间跳到 100%；进度时间分钟两位补零；横屏沉浸页封面不再与文字重叠。
