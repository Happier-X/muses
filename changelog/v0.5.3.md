# v0.5.3

## Windows 桌面端

- **系统托盘**：托盘常驻，菜单支持播放控制与主窗口唤起
- **SMTC 媒体浮层**：接入 Windows 系统媒体控制，浮层展示曲目信息，支持系统级播放/暂停/切歌按键
- **应用图标**：MSI 安装包与托盘应用图标落地
- **安装包**：MSI 补齐开始菜单/桌面快捷方式，固定升级标识保证覆盖安装
- **桌面歌词**：播放页歌词面板上收共用，接入库数据链与在线歌词搜索
- **最小化**：标题栏最小化按钮实现真最小化

## 刮削 KMP 化

- **引擎上收**：文本/封面/队列/编辑信息刮削引擎迁入共享层，安卓与桌面共用同一套实现
- **写回链 Port 化**：WebDAV 客户端接口上收，标签写回引擎跨平台复用
- **桌面装配**：桌面端接入真实刮削引擎（DesktopWebDavClient + DesktopScrapeGraph）
- **修复**：安卓本地歌曲写回补 sourceType 分流，修复 no_password 误命中

## 歌词 KMP 化

- **模块上收**：歌词存储/绑定/解析全量迁移共享层，27 文件 + 34 用例零改动平移
- **桌面刮削歌词**：core:lyrics 模块重建，桌面刮削歌词维度接通

## 界面共用化

- **刮削页**：刮削组件共用化并两端接入，桌面刮削页队列可用

## 修复

- **安卓顶栏**：顶栏改用 WindowInsets 适配状态栏安全区域，主界面各页不再顶入状态栏
- **歌词**：聚焦行缩放 gutter 预留宽度公式修正

## 工程

- **发包流水线**：沉淀 ci 层发包契约（实测踩坑与变量约定），修复 Release 标题重复 v 前缀
- **工程清理**：移除项目中的 Trellis
