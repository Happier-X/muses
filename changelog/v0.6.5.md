# v0.6.5

## 变更

### 窄屏导航：侧滑抽屉 → 底部悬浮 Dock

- 窄屏不再用侧滑推屏抽屉，改回**底部悬浮导航胶囊**（悬浮迷你条 + 官方 `FloatingNavigationBar` 上下叠放），形态对齐 [Halcyon](https://github.com/Kifranei/Halcyon) 的悬浮 Dock（同为 miuix 体系：容器 `surfaceContainer`、选中 `primary`）
- 抽屉期间的三处额外成本随之消失：
  1. 内容整体右移（推屏）带来的布局与遮挡问题；
  2. 抽屉手势与内容区横向滚动（首页平台/榜单胶囊）抢事件——`startDragImmediately` 与自写 `pointerInput` 两条路都验证过不可行；
  3. 顶部状态栏与底部手势区的 inset 都要自己补（底部胶囊由 miuix 组件自带 inset）。
- 连带恢复：`PhoneBottomChromePadding` 96dp → 184dp（窄屏重新有底栏，列表末项避让同步加大）；移除为抽屉加的 6 个 inset 文件（`bottomSystemBarInset` / `topSystemBarInset` 的 expect/actual，已无消费者）
- 宽屏（≥768dp）保持官方 `NavigationRail` 侧轨不变

## 修复

### 首页歌曲列表没有封面

- **榜单歌曲**：`SongListItem` 的 `SongItem` 数据类原本没有封面字段，首页榜单 20 首全是纯文字；现给 `SongItem` 加**可选** `coverUri`（传了才渲染封面位，不影响曲库/歌单等既有纯文字列表），首页榜单传入各平台远程封面（44dp、SM 圆角）
- **推荐歌曲**（猜你喜欢）：推荐行此前是序号 + 歌名 +（歌手 · 理由），无封面；现改为**封面 + 歌名 +（歌手 · 理由）+ 平台标签**（44dp、SM 圆角），并去掉序号（封面已承担行首的视觉锚点）
- 顺带补上数据层的封面缺口（此前三个来源返回 null，UI 只能落占位）：
  - **QQ（搜索 + 榜单）**：两个接口都不直接给封面 URL，改用专辑 `mid` 拼 `y.gtimg.cn` 标准格式（实测 10/10 成功）
  - **酷狗搜索**：实测 `AlbumImage` 恒为空串，真正有值的是 `Image`（且带 `{size}` 占位符，需替换）
  - **网易搜索**：该接口只给加密 picId（转 URL 需 AES），保持留空由 UI 落占位；网易**榜单**有明文 picUrl，不受影响
- 联网冒烟测试（`ChartProviderSmokeTest`）新增封面断言：QQ 榜单 / QQ 搜索 / 酷狗搜索均 10/10

### 在线音源：沉浸页歌词不显示

- **根因（MuMu 实机排查得出）**：封面/歌词此前只问洛雪脚本的 `pic` / `lyric` 动作。但脚本把这两个动作做成了 **`musicUrl` 的副产品**——直链请求时顺带把歌词/封面写进脚本内缓存，`lyric` / `pic` 只读缓存；而 Muses 的直链是「打开媒体时才换取」→ **切歌瞬间问 lyric 必然为空**，歌词自然不显示（导入的「星海音乐源」正是这种实现）
- 现改为「脚本优先 → Muses 匹配系统兜底 → 延迟重试选优」三段式：
  - **立即上屏**：脚本逐字歌词 > Muses 匹配结果（AMLL → 平台五源 → LRCLIB，与刮削同一条链）> 脚本行级歌词
  - **延迟重试**（1.5s / 3s）：等直链解析完成后回问脚本，命中**真实逐字**才替换
  - 不无脑替换的原因：实测脚本给的平台 LRC 会把末尾 credits 全标成 `[00:00.00]`（时间轴脏），覆盖后歌词会停在制作名单上
- 封面：脚本 `pic` → 搜索结果/榜单自带 → 六源匹配（iTunes→kw→tx→wy→kg→mg）→ 播放器实时 metadata；封面链慢，只在前面都没图时才跑
- 顺带修一个会让问题「永久化」的缺陷：元数据链（脚本歌词形态奇怪、解析异常）一旦抛错会**中断整条观察链**，之后切歌再也刷不出封面/歌词；播放页与迷你条均加异常兜底
- 验证：新增播放页 VM 层测试 5 项（在线·无脚本歌词→匹配上屏 / 在线·脚本逐字→采用 / 在线·脚本行级→不覆盖匹配结果 / 脚本迟到逐字→延迟替换 / 曲库曲目→曲库列）；MuMu 实机确认榜单在线曲目歌词正常（含中英翻译对照）且切歌正常更新

## 说明

- 底部悬浮导航为**图标-only**（label 进无障碍文案），与官方 `FloatingNavigationBar` 默认形态一致
- 窄屏底栏 6 项（首页/曲库/专辑/艺术家/歌单/设置）；刮削与音源仍在 设置 → 工具
- 若后续要 Halcyon 那种「普通 / 模糊 / 液态玻璃」多模式与「底栏项可配置」，需要自研 Dock（Halcyon 的 `FloatingBottomBar` 是 651 行自研实现），当前用的是 miuix 官方组件
