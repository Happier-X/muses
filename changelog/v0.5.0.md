# v0.5.0

## 真磨砂玻璃

- **Haze 真磨砂**：`dev.chrisbanes.haze 2.0.0-alpha03 → alpha05`，`TabsLayout` 全局 `HazeState` + 各页局部 `HazeState`，`hazeSource` 在列表/网格、`hazeEffect` / `hazeBlur` 在 `SaltNavbar`（含 `subnavbar` 工具条）、`MiniPlayerBar` 胶囊与歌曲页悬浮钮 `JumpToCurrentFab`，`blur 20-30dp` + `surface` 基底 + 轻量 `tint`，上下与悬浮钮观感统一。
- **顶部贴合背景**：`SaltNavbar` 改为 `surface #F3F3F3/#202020 + White/Black 0.08 / 20dp` 极轻 `tint`，避免偏白，严格贴合歌曲列表背景。
- **底部与悬浮钮**：`MiniPlayerBar` 胶囊与 `JumpToCurrentFab` 圆钮同步真磨砂，`FAB` 复用 `TabsLayout` 全局 `HazeState` 与底部同源，解决与底部不一致及悬浮感不足（`inset White 0.65 + 4/16 Black 0.08`）。

## 刮削

- **顶部标题固定**：`ScrapeScreen` 顶部 `SaltNavbar` 标题由四态（`匹配中/确认候选/结果`）改为固定 `“刮削”`。

## 依赖

- **全量依赖巡检**：`AGP 9.3.1 → 9.3.2`、`WorkManager 2.10.0 → 2.11.2`（其余 `Kotlin 2.4.10` / `Compose BOM 2026.08.00` / `Media3 1.11.0` / `Room 2.8.4` 等已为最新，`Haze` 保持 `alpha05` 并迁移至 `HazeInput.Sources` 新管线）。

## 其他

- 歌曲/专辑/艺术家/歌单/设置/音源等页 `SaltNavbar` 均已 `Box` 覆盖重构，`LazyColumn`/`LazyVerticalGrid` 为 `hazeSource` 在后，导航栏为 `hazeEffect` 覆盖，列表滚动于玻璃后方。
