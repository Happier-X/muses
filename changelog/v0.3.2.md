# v0.3.2

## 沉浸式播放页 1:1 复刻椒盐（核心）

基于椒盐音乐真实截图逐像素复刻沉浸式播放页，背景沿用 AMLL（`BackgroundRender` + `MeshGradientRenderer`）。

### 布局复刻

- **移除顶部导航**：椒盐无返回/「正在播放」/更多按钮，歌名+歌手改为左上竖排（20px 白 / 13px 半透明白）。
- **大封面正方形**：封面 `aspect-ratio: 1` 居中（弹性区 `max-height: min(50vh, 420px)`），不再拉伸变形。
- **信息页/歌词页标题艺术家样式统一**：两边一致（20px/600/白 0.95 + 13px/400/白 0.6）。
- **播放按钮**：透明背景（无圆底）+ 白色图标，与上一曲/下一曲同尺寸（48px + 28px 图标）。
- **MPopup transparent**：播放页面板+backdrop 透明，下滑关闭时露出底下歌曲列表（此前是不透明白底）。

### 歌词系统（AMLL 式）

- **三行歌词上下文**：封面下方显示前一行/当前行（高亮）/后一行，随播放实时滚动。
- **五行窗口连续滚动**：当前行居中（79px 视口 + overflow hidden），切行时窗口整体上移（0.4s 丝滑缓动），当前行 scale 1.05 高亮、前后行 scale 0.92 + blur 淡化。
- **响应式**：屏幕上下太窄（≤520px）时自动收成一行；歌词区与进度条间距拉开（32px）。
- 修复：TDZ 初始化错误导致面板空白、页面跳动、滚动左对齐偏移等。

## 歌曲页 1:1 复刻椒盐

- 移除行内圆按钮/HQ 标识；标题色改中性深灰 #191919（对齐椒盐实测）。
- MiniPlayer 液态玻璃胶囊（白 72% + blur20 + 圆角 40px）+ 深色实心 lucide 图标。
- FAB 玻璃定位按钮、navbar/工具条对齐椒盐、跳转气泡逻辑。

## UI 组件

- **MIconButton 统一图标按钮**：半透明圆形涟漪 + motion 弹簧缩放反馈，替换全部手写图标按钮。
- MActions 修复：Teleport 到 body 解决 transform 祖先导致的操作表偏左。
- 点击行内 ⋮ 不触发行高亮；lucide 线条图标 fill+stroke 双轨修复（不再碎裂）。
