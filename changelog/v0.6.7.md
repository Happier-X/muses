# v0.6.7

## 变更

### 曲库页顶部 tab 收成紧凑居中（对齐 miuix 官方尺寸）

- 背景：v0.6.6 把曲库页 tab 从 `TabRow` 换成 `TabRowWithContour` 后，仍按整行 `fillMaxWidth`
  均分成三个大胶囊，观感与 HyperOS 的分段控件差别明显（miuix 源码里每个 tab 限宽 76~98dp，
  官方 demo 放页面级 tab 时用的是非 contour 的 `TabRow`，`TabRowWithContour` 多用于卡片内）
- 处理：`feature/library/src/commonMain/kotlin/com/muses/player/feature/library/LibraryScreen.kt`
  用一个限宽（252dp ≈ 3 × 76dp + 2 × 9dp 间距）的**外层 Box 收窄约束**再居中
  - 踩坑：`Modifier.width(...)` 不能直接传给 TabRow 的 `modifier` —— 组件内部是先
    `fillMaxWidth()` 再 `then(modifier)`，那样只会把内容往里挤、整条仍然撑满
- 实测（模拟器截图）：三个 tab 收成紧凑居中，选中项为白色圆角滑动块

### 沉浸页转场掉帧 + 「方卡片」

- 掉帧根因：转场进度（`shellProgress`）此前作为**参数**传进 `PlayerShellBox`，等于在组合期读取
  `State` → 进度每帧变化就**重组整棵沉浸页**（歌词 + 封面 + 模糊背景全在里面），380ms 内每帧一次
  - 修复：改成传 lambda（`progress: () -> Float`），只在 `offset {}` / `graphicsLayer {}` 的 lambda
    里读取 → 只让该绘制层失效重绘，不再触发组合
- 圆角：卡片圆角基数 12dp → **28dp**（= 迷你条胶囊半径 56dp / 2），到全屏收到 0；
  之前 12dp 在转场中期只剩几 dp，看着就是个方块（转场起止也不再是「直角弹出」）
