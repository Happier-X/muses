# v0.6.7

## 变更

### 曲库页顶部 tab 收成紧凑居中（对齐 miuix 官方尺寸）

- 背景：v0.6.6 把曲库页 tab 从 `TabRow` 换成 `TabRowWithContour` 后，仍按整行 `fillMaxWidth`
  均分成三个大胶囊，观感与 HyperOS 的分段控件差别明显（miuix 源码里每个 tab 限宽 76~98dp，
  官方 demo 放页面级 tab 时用的是非 contour 的 `TabRow`，`TabRowWithContour` 多用于卡片内）
- 处理：`feature/library/src/commonMain/kotlin/com/muses/player/feature/library/LibraryScreen.kt`
  用一个限宽（252dp ≈ 3 × 76dp + 2 × 9dp 间距）的**外层 Box 收窄约束**再居中
  - 踩坑：`Modifier.width(...)` 不能直接传给 TabRow 的 `modifier` —— 组件内部是先
    `fillMaxWidth()` 再 `then(modifier)`，那样只会把内容往里挤、整条仍然撑满
- 实测（模拟器截图）：三个 tab 收成紧凑居中，选中项为白色圆角滑动块

### 沉浸页转场掉帧 + 「方卡片」

- 掉帧根因：转场进度（`shellProgress`）此前作为**参数**传进 `PlayerShellBox`，等于在组合期读取
  `State` → 进度每帧变化就**重组整棵沉浸页**（歌词 + 封面 + 模糊背景全在里面），380ms 内每帧一次
  - 修复：改成传 lambda（`progress: () -> Float`），只在 `offset {}` / `graphicsLayer {}` 的 lambda
    里读取 → 只让该绘制层失效重绘，不再触发组合
- 圆角：卡片圆角基数 12dp → **28dp**（= 迷你条胶囊半径 56dp / 2），到全屏收到 0；
  之前 12dp 在转场中期只剩几 dp，看着就是个方块（转场起止也不再是「直角弹出」）

### 沉浸页开合改成「等比浮入」（对齐椒盐音乐）

- 之前不自然的根因：卡片按「迷你条矩形 → 全屏矩形」**非等比**插值（scaleX / scaleY 分别算），
  而迷你条是宽扁矩形（约 972×168），于是转场中文字与封面被横向拉伸、竖向压缩
- 现在：整页**等比缩放**（scaleX == scaleY，0.92 → 1）+ **从屏幕下方浮入** + 圆角 **28dp → 0**
  - 以底部中心为原点，缩放时卡片底部不动、向上展开
  - 不再依赖迷你条矩形做形变起点（`miniBarBounds` 及其上报链路一并移除）
- 实测（模拟器把系统动画放慢 30× 抓帧）：卡片带明显大圆角从底部浮出，内容比例正常、不变形，
  卡片外是干净的主页面

### 沉浸页转场：改为「从迷你条位置生长」+ 除封面外内容渐隐（对齐椒盐音乐）

- 上一版的问题：起点在**屏幕外底部**（「等比浮入」），与迷你条之间没有任何几何联系，
  观感只是「一块卡片从下面冒出来」——用户报障「并没有从迷你播放条弹过渡到沉浸式播放页面」，
  且转场中期卡片是方形（圆角已修，但形态仍不对）
- 处理（`feature/shell/.../MusesApp.kt` + `feature/player/.../PlayerScreen.kt`）：
  1. 恢复**迷你条矩形上报**（`boundsInWindow`，融合态 `CompactPlayerDock` 与展开态各一实例都要报）；
     `PlayerShellBox` 起点由该矩形决定：
     - 缩放**只按宽度比** `miniBounds.width / fullWidth`（等比 → 内容永不变形），
       起点时卡片横向与迷你条等宽
     - 平移把卡片中心对齐到迷你条中心，`p = 1` 时位移归零即全屏
     - 用 `translationX/Y` 而非 `offset`：不进布局，避免每帧重新摆放内容
     - 拿不到矩形时（首帧）退化为原「底部浮入」兜底
  2. **除封面外的内容随进度渐隐**（`contentAlphaFor`：进度 < 0.45 完全不可见，
     之后按 `FastOutLinearInEasing` 浮现）：标题、歌词面板、进度条、控制按钮
     → 点开先看到「封面飞出来」，内容后半段才浮现；收起时相反
     - 封面本身仍走 share element（`PlayerArtworkSharedKey`），不受这个 alpha 影响
- 实测（模拟器系统动画放慢 10× 抓帧）：打开早期只有封面可见、卡片从迷你条位置生长；
  中期内容浮现；关闭时内容先隐、封面缩回迷你条位置——两向对称
