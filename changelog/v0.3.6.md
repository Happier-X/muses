# v0.3.6

## 播放页：平板模式沉浸布局（双栏 + 底部全宽控制条）

- **横屏平板（≥768px 且宽>高）双栏重构**：左栏 = 歌名/艺术家头部 + 大封面（垂直居中）；右栏 = AMLL 歌词；进度条 / 上一曲·播放·下一曲 / 循环·随机·队列·更多 **全部下移到底部全宽控制条**（三段式：左端循环/随机、居中主控、右端队列/更多），进度条横跨全宽可拖动 seek。
- **断点机制重构**：平板判定从 media query 改为 JS class 驱动（`isTabletLayout = width >= 768 && height < width`），**竖屏平板（如 800x1280）保持手机式全屏沉浸**（固定头部 + 五行歌词 + 内嵌控制），与椒盐竖屏行为一致；横屏窄高手机不受影响。
- **背景**：保持 AMLL 封面氛围背景，双栏左右共享全屏铺满。
- **交互回归**：进度 seek / 循环切换 / 更多菜单 / 歌词浮动 chrome（平板只留翻译 FAB）在平板下均正常；手机布局零改动。
