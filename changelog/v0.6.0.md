# v0.6.0

## 修复

- **导航栈切 tab 丢状态**：切 tab 时清到只剩 `Songs` 垫底再 push，新 tab 永远压在歌曲页之上，返回先落到歌曲页、子页面栈也被丢掉；现 7 个路由归属不变、两端 5 目的地平等主页（整栈替换为新主页单例，全程非空），子页面正常压栈，点当前 tab 直接弹回该主页，系统返回逐级回退、主页不再消费
- **手机端专辑/艺术家/歌单进不去**：窄屏底栏原来只有曲库/音源/刮削/设置 4 栏；现底栏 5 栏（曲库/专辑/艺术家/歌单/设置），宽屏 Rail 同步精简到同一套 5 个（首项统一叫「曲库」，次组为空不画分割线），刮削/音源收进设置页「工具」区块
- **列表滚到底被悬浮件盖住**：底栏两件套是不透明实色；现新增共用 `LocalBottomChromePadding`（窄屏 184dp / 宽屏 96dp），各列表末项避让、置底按钮叠加避让，空态/短内容不留白
- **底栏三处材质不统一**：迷你条自绘液态玻璃 vs 悬浮底栏/悬浮钮纯色投影；现迷你条与官方底栏一比一同材质（surfaceContainer 纯色 + squircle 50dp + 同款投影），磨砂/描边/透明下线

## 功能

- **当前播放曲整行变蓝**：歌曲列表与歌单详情中正在播的一行，标题和「艺术家 - 专辑」副标题都用主题 `primary` 色（多选时以选中态为准）；`MusesListRow` 新增颜色参数，共用 `SongListItem` 同逻辑
- **歌曲行垂直居中**：更多按钮之前塞在标题行内只跟标题对齐；现挪到外层与整行居中，封面/文字/按钮三居中

## UI 对齐 miuix 官方默认体系

- **页面与顶栏同灰**：顶栏默认 `surface`（浅灰 #F7F7F7）而页面用纯白 `background`，永远两截；现 11 个页面 + 桌面壳/标题栏/双形态布局/根 Scaffold 全切 `surface`，深色模式同步融合；卡片 `surface→surfaceVariant`（灰底白卡，还原 HyperOS 原生样式）、封面槽/搜索框同步提亮、无封面行补灰槽
- **宽屏侧栏换官方 `NavigationRail`**：自绘 260dp 卡片 aside（`NavGroupCard/MusesNavLink` 删除）→ 官方侧轨（折叠 80dp / 展开 240dp，内建切换钮），配色/分割线/边衬全走官方默认
- **桌面标题栏与背景融合**：自绘标题栏底色与应用底色统一，去分割线
- **工具栏与封面左对齐**：歌曲页工具栏/搜索栏加左右 16dp，与歌曲行封面左缘一条线
- **底栏边距对齐**：悬浮底栏 wrap-content 居中比全宽迷你条每边短 6dp；现迷你条边距动态取 `(屏宽-底栏宽)/2`（底栏宽按官方默认值推导），两边一条线
- **底栏底部收紧**：官方默认底部留白 36dp 实测偏大；现整体下移至 ~24dp（手势区安全；offset 必须包在组件外面，经 modifier 参数传进去只动图标不动背景）
