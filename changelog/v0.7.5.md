# v0.7.5

## 新增

- **排行榜详情页**：探索页展示排行榜卡片，点击后进入对应榜单，可浏览并播放榜单歌曲。
- **LX 音源导入**：支持从文件或 URL 添加 LX 音源，并提供导入过程反馈与结果提示。
- **统一空状态**：各页面统一使用带图标、居中展示的「空空如也~」状态。

## 改进

- **曲库扫描**：扫描结果改为合并更新，保留已刮削的封面、歌词和标签；未发现的歌曲标记为丢失，空结果或大幅锐减时保护现有曲库。
- **探索页与音源页**：精简 AI 推荐提示卡，调整榜单浏览交互，并统一音源名称和 WebDAV 表单文案。
- **播放器与歌词**：改进沉浸播放页、歌词显示和播放器交互细节。
- **洛雪脚本兼容性**：为 LX 脚本运行环境补充常用定时器和日志接口。

## 修复

- **在线播放失败处理**：在线直链解析失败或超时时明确报告解析错误，避免将内部 `muslx://` 地址交给 HTTP 播放器并产生误导性错误。
- **曲库数据保护**：修复重复扫描覆盖已有富化信息、扫描源暂时不可用时歌曲从曲库消失的问题。
