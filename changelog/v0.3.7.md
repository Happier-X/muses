# v0.3.7

## 曲库 Tag 治理与批量刮削

- **来源可视化**：曲库详情页展示每个歌曲 tag 的来源平台标识，便于识别元信息出处。
- **匹配质量升级**：优化在线 tag 匹配算法，提升元信息补全的准确率与覆盖率。
- **批量刮削**：支持对曲库批量发起 tag 刮削，一次性补全缺失的 artist/album 等元信息。

## 车载连接修复

- **CarWith 连接修复**：修复 CarWith 车机连接后播放完毕不自动切歌、媒体按钮（上一曲/下一曲/暂停）失效的问题——源头保活 JS 层播放实例。
- **设备断开暂停**：播放中拔出蓝牙/有线/USB 音频设备或断开 CarWith 车机时自动暂停播放，避免无声继续走进度。

## UI 修复

- **侧边栏焦点环**：修复侧边栏菜单首次打开时导航链接出现黄色焦点环的问题——去除默认 `outline`，仅在键盘导航（`focus-visible`）时保留。
- **手势导航底部遮挡**：修复手势导航模式下列表底部内容被 MiniPlayer 遮挡的问题——内容止位 token 移入 `.m-app` 桥接作用域统一计算。

## 歌词修复

- **双语译文偏移**：修复双语歌词译文整体后移一行的问题——译文时间戳在下一句时错配，现已修正对齐逻辑。
