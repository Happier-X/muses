# v0.4.3

> **⚠️ 原生重构首个版本，重要必读**
>
> 本版本起，Muses 从 WebView 混合架构全面重写为 **纯原生 Kotlin + Jetpack Compose**：启动更快、内存占用更低、播放由 Media3 原生驱动、后台发热与耗电显著下降。
>
> 由于存储架构更换，**覆盖升级后需要一次性重新配置**（详见下方「数据迁移说明」）。旧版数据仍保留在设备上不受影响，可随时卸载新版回装旧版。

## 重写带来的改进

- 纯原生 Kotlin + Jetpack Compose UI，Salt Player 风格一比一复刻（歌曲/专辑/艺术家/歌单/队列/音源/设置/播放页全部页面）
- 播放引擎迁移至 Media3 ExoPlayer：媒体通知、蓝牙断连自动暂停、音频焦点处理更可靠
- WebDAV 流播直连原生 OkHttp，配合 LRU 缓存（500MB）在线听歌更流畅
- 歌词渲染接入 AMLL（TTML 逐词卡拉OK染色），本地内嵌/sidecar 歌词直接解析
- 播放失败自动恢复：单个文件损坏或网络抖动不再卡死队列，自动跳到下一首可播曲目并给出友好提示
- 关闭应用后播放队列与进度完整保留，冷启动原地续播
- 最近播放记录（上限 50 条）

## 数据迁移说明（重要）

因存储架构更换，**以下数据需要重新配置一次**：

1. 重新添加音源（本地文件夹 / WebDAV）并执行扫描
2. 重新输入 WebDAV 账号密码（密码现在改用 Android Keystore 加密存储，更安全）
3. 歌单需要在曲库扫描完成后重建
4. 设置项（响度均衡等）恢复默认值

> 你的旧版数据文件并未被删除，如需回退可直接卸载新版后安装 v0.4.2。

## 修复

- 继承并修复 v0.4.2 全部问题项（WebDAV 回写原子覆盖、刮削历史、后台渲染降载等能力均已在原生层重新实现或规划中）

## 已知限制

- 刮削（元数据/封面/歌词在线补全）的入口页面将在后续版本回归，引擎已完成重构
- 平板双栏布局持续完善中
