# v0.3.0

## 导航栏玻璃效果修复（核心）

- **歌曲页导航栏改覆盖式布局**：导航栏悬浮覆盖在列表之上，列表内容从导航栏后方滚过，恢复 Konsta 官方 iOS 的滚动模糊玻璃效果（顶部实色 + 下半渐显 + 内容模糊透出）。
- **统一推广到音乐库详情、歌单详情、设置、音源 4 页**（音乐库分段页保留常驻吸顶分段条，不做覆盖式）。
- 补齐 Konsta 官方 mask 渐显工具类（此前未生成，导航栏/工具栏下半 blur 渐显实际无效），导航栏玻璃恢复完整官方效果。

## 随机播放吸顶条修复

- 修复滑到顶部时随机播放按钮被歌曲列表遮挡的问题（sticky 流占位错位：吸顶条占位与显示位置不一致，第一首歌盖住按钮上半部）。
- 吸顶条改用 **k-glass 组件**，玻璃配方与导航栏完全同构（blur 2px + 下半渐显 + 页面同色渐变），滚动时歌曲从玻璃条后方模糊经过。

## 界面细节

- MiniPlayer 改用 Konsta k-glass 组件（官方玻璃配方，去手写玻璃样式）。
- toast 文字显式设色（浅色黑字 / 深色白字），修复浅色玻璃上白字不可见。
- backdrop-blur-lg 直接给值修复旧 WebView 上玻璃模糊失效（MiniPlayer / 弹层玻璃全受益）。
