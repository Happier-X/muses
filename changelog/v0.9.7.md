## 新增

- 应用内更新：安卓端可在应用内完成「检查 → 下载 → 安装」，下载后交给系统安装器覆盖升级（不弹「打开方式」选择器，也不会被第三方应用商店接管）；桌面端沿用同一张更新卡片，安装 MSI。
- 启动自动检查更新：每天静默检查一次，有新版时弹窗展示更新日志，可直接下载安装，也可选「稍后」。
- 更新日志弹窗：按 Release 正文展示，去掉 markdown 标记，超出高度可滚动。

## 改进

- 检查更新增加退路：GitHub API 对共享出口 IP 限流时，改读 Release 页跳转并按发版产物命名拼接下载直链，不再直接报「检查失败」。
- 在线曲目歌词上屏提速：不再先等封面，已匹配的行级歌词立即显示，逐字结果到达后再升级。
- 首页入口统一为「首页」（原「探索」）。

## 修复

- 修复推荐歌单详情页首屏重复出现加载提示的问题。

## 清理

- 删除无人引用的曲库组件（`LibraryComponents.kt`）与旧版导航抽屉、未使用的导航常量，合计约 700 行。

## 说明

- 应用内更新的最终覆盖安装依赖同签名：模拟器上安装的是调试包，与正式包签名不同，安装会提示「签名不一致」，属预期；正式包之间的升级未实测。
- 桌面端的更新弹窗只通过编译验证，未在桌面实机运行。
- 每天一次的自动检查若当天请求失败，不会当天重试，可在设置页手动检查。
- 更新包下载到应用私有目录（安卓 `files/updates`、桌面 `%LOCALAPPDATA%/Muses/updates`），不会自动清理。
