# v0.3.3

## 播放页修复与完善

- **三行歌词裁剪修复**：五行歌词窗口稳态偏移修正（-19.5px → -29.5px，CSS 变量管理），第三行不再被视口裁掉半行；切行动画复位无跳变；窄高屏（≤520px）单行模式当前行完整可见。
- **封面自适应**：封面尺寸跟随可用弹性区（正方形边长 = min(容器宽, 容器高)），大屏空间富余时自动变大，恒为正方形。
- **Toast 被播放条遮挡修复**：Toast 改为 Teleport 到 body 渲染，脱离页面层叠上下文，不再被底部 MiniPlayer 盖住；真机 safe-area 两级兜底。
- **平板左右分栏**：平板（≥768px）沉浸播放页恢复左右布局（左侧播放控制页 + 右侧歌词页），左侧不再展示三行歌词；修复右侧歌词面板在平板下被裁出视口的问题。

## 椒盐视觉复刻

- **MToggle 椒盐开关**：46×26 胶囊轨道 + 白色圆环拇指（中心露轨道色圆点），开启右移、轨道色 300ms 渐变，深浅主题双配方。
- **图标按钮统一 MIconButton**：播放页主控/模式/歌词 FAB 全部改用图标按钮组件（新增 48px 尺寸档）；点击反馈改为椒盐实测的「图标按下变暗」（无圆底、无缩放）。
- **播放条/FAB 液态玻璃**：MiniPlayer 与跳转 FAB 对齐椒盐 Liquid Glass——高白底（0.85）+ 强模糊（30px）+ 边缘高光，底下列表内容模糊可见；深色主题配套配方。
