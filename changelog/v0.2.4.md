# v0.2.4

## 播放与预取

- **WebDAV 下一首元信息预取**：播放成功后预取下一首在线歌词 / 封面 / 文本并写回曲库；不写当前 `playerState`，独立 token 防串曲；无密码时仍可预取元信息。

## 沉浸式播放页

- **内容层 safe-area**：全屏 HPopup 背景 edge-to-edge；内容与歌词 FAB 使用 `var(--safe-area-inset-*, env(...))` 三级回退；宽屏断点只减固定 px，不再抹掉顶部安全区。
- **下滑关闭不再露白**：宿主透明化 Player 的 HPopup panel；下滑只平移内层背景，露顶透过 dim overlay 看底层页。
- **竖屏控制页排版**：封面 + 信息 + 控件整体垂直居中并收紧间距，封面槽不再 flex-grow 顶开。
- **歌词浮动 chrome**：FAB 用真实 `color`/`background` 覆盖 HButton ghost 默认黑字；无译文/音译时不展示翻译键；宽屏无译不挂空 chrome。

## 歌曲列表

- **跳转当前曲 FAB**：虚拟列表仅用 `scrollToIndex` 定位；去掉 `scrollIntoView` 与错误 `scroll-mt`，修复二次点击当前行下移。
