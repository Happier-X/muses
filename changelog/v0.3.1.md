# v0.3.1

## 全量迁移自研 m-* 组件集 + SCSS 样式体系（核心）

彻底移除 Konsta UI 组件库与 Tailwind CSS，所有 UI 控件改为自研 `m-*` 组件集，样式架构改为全量 scoped SCSS + 全局 `--m-*` 变量体系。视觉与交互零回归。

### 自研组件集（28 个）

- **按钮**：MButton、MFab、MNavbarBackLink
- **导航**：MNavbar、MTabbar + MTabbarLink
- **列表**：MList、MListItem、MListInput、MBlockTitle
- **表单**：MToggle、MCheckbox、MRange
- **分段**：MSegmented + MSegmentedButton
- **浮层**：MPopup、MSheet、MDialog + MDialogButton
- **操作表**：MActions + MActionsGroup + MActionsButton + MActionsLabel
- **提示**：MToast、MPreloader
- **展示**：MCard、MCover、MEmpty

API 对齐原 Konsta 使用面，页面只改标签与 import 名；动画全部走 motion-v（`AnimatePresence` + `motion.div` + `animate()` 命令式），唯一例外是纯颜色/背景渐变过渡保留 CSS transition。

### 样式架构

- 全局主题入口 `src/theme/index.scss`：`--m-*` 变量体系（浅色/深色双套）、玻璃/mask 工具类、安全区桥接（`--m-safe-area-*`）、弹层 z-index 阶梯（950/1000/1100/1200/1300）。
- 所有组件使用 `<style scoped lang="scss">`，Tailwind 工具类彻底移除。
- WebView < 111 兼容修复保留：backdrop-filter `-webkit-` 双写、渐变禁 oklab 插值、mask 渐显。

### 页面迁移

App / MiniPlayer / TabsPage / CategoriesPage / AlbumsPage / ArtistsPage / PlaylistsPage / SettingsPage / SongsPage / LibraryDetailPage / PlaylistDetailPage / SourcesPage / QueuePage / PlayerPage 全量迁移完成。

## 移除的依赖

- `konsta@5.3.0`
- `tailwindcss@4.3.3`
- `@tailwindcss/vite`
- postcss.config.js / tailwind.css 配置文件

## 新增的依赖

- `motion-v@2.3.0`
