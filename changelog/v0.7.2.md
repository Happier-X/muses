# v0.7.2

## 新增

- **AI 推荐服务配置**：支持自定义 OpenAI 兼容服务地址、模型和 API Key，并可从服务端获取模型列表。
- **AI 服务独立设置页**：将服务配置从设置主页拆分到二级页面，首页推荐入口可直接前往配置。

## 改进

- **设置页**：精简设置项说明；版本号移至右侧，更新检查状态替换右侧箭头，报错日志入口更简洁。
- **音源管理**：简化音源列表，将添加 LX 音源入口收进添加操作。
- **刮削页面**：从设置页进入时作为设置子页面显示，支持返回并保持设置导航选中，统一页面底色。
- **播放页转场**：修复沉浸式播放页开合与封面过渡问题。
