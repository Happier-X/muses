# v0.5.7

## 修复

- **沉浸式播放页底部控件被遮挡**：`Scaffold` 的 `bottomBar`（迷你播放条 + 悬浮导航栏）绘制层级在 body 之上，播放页 overlay 留在 body 内会被白色条盖住底部进度与控件；现把 overlay 移到与 `Scaffold` 平级，必然盖过 bottomBar，恢复「全屏盖住不可见、不可交互」的预期层级
- **曲库页「跳转当前曲」悬浮钮位置**：随 miuix `FloatingActionButton` 迁移后按视口宽度抬升（窄屏避开迷你条 + 悬浮底栏 148dp，宽屏仅迷你条 96dp），不再贴屏底被底栏压住

## UI 对齐 miuix 官方默认体系

- **主题**：`MusesTheme` 改用官方 `ThemeController(ColorSchemeMode.System)`（内置跟随系统深色，`isDark` 可显式覆盖），替换手写的 `isSystemInDarkTheme()` 二选一
- **颜色**：散落的硬编码颜色对齐官方 `colorScheme` token——删除按钮/刮削错误状态 → `error`，迷你条与玻璃面板描边 → `outline`，跳转悬浮钮毛玻璃基底 → `surfaceVariant`，桌面 Toast → `surfaceVariant` + `onSurface`（明暗随主题）
- **文本**：139 处硬编码 `fontSize` 清零，全部走 `MiuixTheme.textStyles` 官方档位；无对应档位的吸附最近档（12→`footnote1`、15→`body1`、9/10→`footnote2`），播放进度时间行的 `tnum` 数字等宽特性经 `token.copy` 保留
- **有意保留**：沉浸式播放页深色底/白色歌词、刮削 SUCCESS/WARNING 状态语义色——设计固有视觉，非主题范畴

## 清理

- **删除不可达的备选歌词实现**：`AlternativeLyricsPanels.kt`（EVA / TextPV 文字视觉 / Skyline 横屏歌词，`lyricsStyle` 写死 AppleMusic，运行时永不可达）及 `Stubs` 中 `LyricsStyle`/`TextPVStyle`/17 个 `skyline*` 常量，净删约 770 行
- **删除自绘阴影系统**：`MusesShadows` 三件套（SCSS `box-shadow` 令牌翻译 + 安卓 nativeCanvas 实现 + 桌面简化实现）随唯一使用方迁移一并下线；曲库页悬浮钮换用 miuix 官方 `FloatingActionButton`（自带 `shadowElevation`）
