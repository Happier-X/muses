# v0.5.2

## 界面架构重构（KMP 共用化）

- **界面共用模块**：新建 `ui-shared` 模块，按钮、开关、列表、空态、主题、图标等基础组件由安卓与桌面共用同一套实现
- **页面共用化**：设置页、音源管理、WebDAV 浏览、曲库主页、歌单、播放页控制栏等逐步上收共用，安卓与桌面体验统一
- **平台接口**：安全区域、模糊、Toast 等平台能力抽象为统一接口，两端各自实现

## Windows 桌面端

- **桌面播放**：基于 VLCJ 的桌面播放端口，支持队列状态机与 WebDAV 缓存
- **桌面三屏**：库房、播放、设置最小可用，支持 WebDAV 音源管理
- **安装包**：发版自动构建 Windows MSI 安装包，与安卓包同一次发布

## 图标与依赖

- **图标库**：从 Lucide 切换到 Tabler Icons
- **依赖注入**：Hilt 全量切换为 Koin，修复启动闪退
- **数据层**：Room 与 DataStore 搬入 KMP 共用层

## 播放器修复

- **播放页**：顶部适配状态栏安全区域，进度条拖动不再与左右滑冲突
- **侧边栏**：已打开时继续右滑不再误关闭
- **歌词**：沉浸式歌词当前行居中，主行字号与字重优化
