# v0.4.4

## 新增

- **本地文件夹一键接入**：音源页新增「添加本地文件夹」系统目录选择器（SAF），拉起系统 DocumentsUI 选目录后自动以目录名建源、持久化访问权，无需手填路径；原手填表单保留为高级入口

## 修复

- **播放页黑屏修复**：移除 M1 时代为 MuMu 加的 `LAYER_TYPE_SOFTWARE` 强制软件层（大尺寸 WebGL 在软件管线下整层不上屏），恢复硬件加速；修复 `html/body height:100%` 在 WebView 中塌陷为 0 导致 `#player-ui` 高度为 0 的黑屏，改为 `100vh` 相对视口

## 刮削限流与 429 自愈

- **全局 4 rps 限流**：刮削 `ScrapeHttp` 新增 `ScrapeRateLimiter`（250ms 间隔，`Mutex` + `delay` 非阻塞），`ScrapeModule` 单例跨文本/封面/封面字节三链路共享；队列 20 首不再瞬发 50+ 请求
- **429 退避重试**：解析 `Retry-After`（秒数 / HTTP-date，≤8s 截断），首次 429 延迟后重试 1 次，二次 429 抛 `IOException("http 429")` 并归类为 `NETWORK`
- **负缓存隔离**：`TextMetaMatcher`/`CoverMatcher` 仅 `NO_MATCH` 写负缓存，`NETWORK` 不写；新增 `invalidateNegativeCache(songId)` 供单曲重试前失效
- **UI 可观测**：`matching` 态显示「等待限流恢复…」，`preview/result` 行显示「触发限流，稍后重试」并支持单曲重试，重试时自动失效负缓存

## WebDAV 播放限流与退避

- **播放/刮削共享限流**：新增 `WebDavRateLimiter` 单例（4 rps/250ms，`synchronized` 兼顾协程/阻塞），`ScrapeRateLimiter` 复用为其 `typealias`；`WebDavClient` 全量方法前 `acquire()` + `OkHttp` 拦截器 `acquireBlocking()` 双层覆盖，已限流请求打 `X-Muses-Rate-Limited` 跳过二次限流
- **流播剥离限流**：`WebDavModule` 新增 `@StreamingOkHttp` 限定 client（只注入 Basic Auth，不施加 4 rps），`PlaybackService` 的 `OkHttpDataSource`/`CacheDataSource` 改走该 client；流播单连接串行读取不再被限流饿死或超时重试叠加 429
- **429 退避与提示**：`WebDavClient` 解析 `Retry-After` 退避重试 1 次，二次 429 抛错并 `ErrorLogStore.log(WARN)`；播放页消费 `playbackError` 显示「触发限流，稍后重试」`Snackbar`（重试/关闭），`ErrorLogStore` 可查 `WARN WebDavClient http 429`
- **服务端指引**：新增 `server-guide.md`，给出 Cloudflare 对 `/dav/*` 跳过限流/WAF 的配置清单

## 播放与数据

- **播放标签直连 ExoPlayer**：移除 WebDAV 懒扫描回写链路，标题/时长优先回退 `MediaMetadata`（与通知栏同源），`TagReader`/`CoverCacheWriter` 整文件下载不再触发；重复播放命中 `CacheDataSource` 本地缓存
- **删源同步清理播放状态**：删除音源时同步清理 `PlaybackStateRepository` 快照、`RecentPlays` 及 `ExoPlayer` 队列，避免底部栏残留已删源歌曲
