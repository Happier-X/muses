# v0.4.8

## 重构

- **卡拉OK 歌词渲染器改为内嵌源码**：不再依赖 `com.mocharealm.accompanist:lyrics-ui` AAR，将 AMLL 官方 Compose 渲染器（Accompanist lyrics-ui 1.0.19）的 12 个源文件 vendored 进 `feature/player/src/main/kotlin/com/mocharealm/accompanist/lyrics/ui/`，外部依赖与第三方包约束全部消除，行为完全可控可调。
  - 保留上游包名 `com.mocharealm.accompanist.*`，便于与上游 `diff` 对比和后续同步。
  - 本地化适配三处：
    1. `expect`/`actual`（Kotlin Multiplatform）折叠为普通 Kotlin——`Char.isCjk` / `isArabic` / `isDevanagari` 的 Android 实现直接并入 `utils/String.kt`；
    2. 移除 gaze-capsule 依赖——`LyricsLineItem` 的 `ContinuousRoundedRectangle` 替换为 `androidx` 的 `RoundedCornerShape`；
    3. 去掉 `ExperimentalAnimatableApi` opt-in——AndroidX Compose 1.12 起 `DeferredTargetAnimation` 已稳定、该注解被移除（上游面向 JetBrains Compose 仍保留）。
  - 新增 `docs/THIRD_PARTY.md`：记录来源、Apache 2.0 许可声明、内嵌文件位置与上述改动说明。

## 其他

- `gradle/libs.versions.toml` 移除 `lyrics-ui` 版本与库条目，`feature/player/build.gradle.kts` 移除对应 `implementation`。
- minSdk 维持 29（`BlurEffect` 需 API 31+ 才生效，29/30 上自动降级为无模糊）。
- 歌词效果与 v0.4.7 一致（逐词渐变、字符动画、距离模糊、Plus 发光、间奏呼吸点、自动滚动）；本次为依赖形态变更，不含视觉改动。
